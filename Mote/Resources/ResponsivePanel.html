Responsive preview

Your viewports appear in the main browser area.

Edit, rotate or remove a viewport using its menu above the preview.

Previews fit the available browser area up to the selected scale. Device dimensions stay unchanged.

Select another inspector tab or close the inspector to return to your original page.

These previews use WebKit on macOS. Viewport dimensions and custom user agents do not emulate a different browser engine, touch gestures, locale or safe areas.
